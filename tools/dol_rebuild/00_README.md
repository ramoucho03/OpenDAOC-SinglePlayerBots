# DOLSharp Full Rebuild

Generated by `gen_full_rebuild.py`. Wipes the world-content
tables and rebuilds them from the DOLSharp `db-public` dataset
(post-Catacombs content: full Heretic/Warlock/Vampiir/Mauler spells,
all keep components, 16k localised strings, 146k mob spawns, etc.).

**Player/progress tables are NEVER touched.** See `KEEP_TABLES`
inside the generator for the full list. Anything not listed there
and not listed in `REBUILD` is left alone (cosmetic OpenDAoC
custom tables, etc.).

## How it ships

These SQL files are **appended to `combined.sql` at docker build time**
(see the `RUN if [ -d /build/tools/dol_rebuild ] ...` block in the
top-level `Dockerfile`). So on a fresh `docker compose up -d`:

1. MariaDB initialises an empty volume.
2. The `db-seed` sidecar drops `combined.sql` (OpenDAoC schema + 1.65
   baseline + this DOLSharp rebuild) into the init directory.
3. MariaDB runs the SQL: tables are created, then wiped of the OpenDAoC
   baseline data, then reloaded from DOLSharp.

Existing DBs are **not** re-seeded. The init directory only fires on a
brand-new volume. To reset an existing deployment to the DOLSharp baseline:

```bash
docker compose down -v   # DESTROYS the DB — back up first
docker compose up -d
```

To re-apply the rebuild manually against an existing DB without nuking it:

```bash
bash tools/dol_rebuild/run_all.sh
```

## To disable DOLSharp content (revert to vanilla OpenDAoC)

Delete this folder, rebuild the image, and reset the volume.
